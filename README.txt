InteriorFlux website
====================
index.html      - page structure and content
css/style.css   - all styling (theme colours are the variables at the top)
js/theme.js     - loads saved light/dark theme (runs in <head>)
js/main.js      - page behaviour
assets/         - images (home.jpg, work.jpg, report.jpg)

To preview: open index.html in a browser.
To publish: drag this whole folder (or the zip) onto Netlify Drop, or push it to GitHub Pages / Cloudflare Pages / Vercel.
